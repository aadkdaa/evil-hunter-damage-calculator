# 작업 지침

## 이 프로젝트에서 할 일

- 이블 헌터 타이쿤의 데미지 공식을 자료, 게임 테스트, 기존 계산기 및 추후 APK 분석을 통해 점진적으로 파악한다.
- 확인된 공식을 바탕으로 사용자의 현재 상태를 입력해 데미지를 계산하는 Google Sheets를 조금씩 만든다.
- 계산기는 다음 Google Sheets 문서에 만든다: https://docs.google.com/spreadsheets/d/1n7DTvjvw3jlfOB-n3UmhovxKqsJxsMAn1tMMawWiyMw/edit?gid=0#gid=0
- 프로젝트의 상세 목적과 현재 범위는 docs/프로젝트_개요.md를 기준으로 한다.

## 기본 원칙

- 사용자가 제공하는 정보는 내용에 맞게 분류하여 별도의 Markdown 문서에 기록한다.
- 조사 결과, 실험값, 공식, 용어, 출처 및 작업 이력을 AGENTS.md에 직접 누적하지 않는다.
- 기존 분류에 해당하는 문서가 있으면 그 문서를 갱신하고, 새로운 분류가 필요하면 docs 폴더에 새 Markdown 문서를 만든다.
- 하나의 문서에는 가능한 한 하나의 주제만 다룬다.
- 사용자가 확정이라고 알려 준 정보는 확정값으로 기록한다. 임의로 가설이나 추가 검증 대상으로 낮추지 않는다.
- 추정한 내용은 확정된 정보와 구분하여 가설임을 표시한다.
- 수치와 명칭은 사용자가 제공한 원문을 우선하여 정확하게 보존한다.
- 인터넷 자료를 기록할 때는 출처 URL과 확인 날짜를 함께 남긴다.
- 중요한 추가, 수정 및 판단 변경은 docs/히스토리.md에도 간단히 기록한다.

## 파일 작업

- 원본 엑셀과 참고 이미지는 덮어쓰거나 수정하지 않는다.
- 중간 산출물과 수정본은 목적과 버전을 알 수 있는 별도 파일로 저장한다.
- 요청과 관계없는 사용자 파일은 수정하거나 삭제하지 않는다.
