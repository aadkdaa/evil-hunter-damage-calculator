# 유물 직업 증폭 클뜯 정보

## 분석 범위

- 대상 APK: v1.376
- 확인일: 2026-09-03
- 분석 방식: APK 에셋과 복호화된 ARM64 IL2CPP 코드 정적 분석
- 실행 중인 앱, LD플레이어, 프로세스 메모리 및 보안 모듈은 사용하지 않음

## 대상 옵션

유물에는 다음 다섯 가지 직업 계열 피해량 증폭이 존재한다.

- 버서커 계열 직업 피해량 증폭
- 팔라딘 계열 직업 피해량 증폭
- 레인져 계열 직업 피해량 증폭
- 소서러 계열 직업 피해량 증폭
- 다크나이트 계열 직업 피해량 증폭

이 효과는 공격 대상의 직업을 보는 것이 아니라, 피해를 주는 헌터 자신의 기본 직업 번호를 기준으로 선택된다.

## 결론

유물 직업 증폭은 헌터 상세창의 계산 공격력에 반영되지 않는다.

- 상세창 공격력: 변하지 않음
- 상세창 초당공격력: 변하지 않음
- 실제 타격 데미지: 해당 직업 계열의 증폭 배율 적용

따라서 계산기에서는 공격력 증가 그룹이 아니라 실제 데미지의 최종 증폭 그룹으로 처리해야 한다.

## 적용 공식

```text
직업증폭배율
= 1 + (도감의 해당 직업 증폭% + 유물의 해당 직업 증폭%) ÷ 100

직업증폭 적용 데미지
= 기존 데미지 × 직업증폭배율
```

도감과 유물의 같은 직업 증폭은 서로 곱하지 않고 먼저 합산한다. 합산된 직업증폭배율은 다른 데미지 계수들과 곱해진다.

예시:

```text
도감 버서커 계열 증폭 = 10%
유물 버서커 계열 증폭 = 20%

버서커 계열 헌터의 직업증폭배율
= 1 + 0.10 + 0.20
= 1.30
```

이 경우 상세창 공격력은 그대로지만 실제 데미지는 1.30배가 된다.

## 직업 선택 방식

| 기본 직업 번호 | 적용하는 유물 증폭 |
| ---: | --- |
| 0 | 버서커 계열 증폭 |
| 1 | 팔라딘 계열 증폭 |
| 2 | 레인져 계열 증폭 |
| 3 | 소서러 계열 증폭 |
| 4 | 다크나이트 계열 증폭 |

공격 헌터의 기본 직업과 일치하지 않는 다른 계열 증폭은 해당 데미지에 적용되지 않는다.

## 상세창 공격력과의 구분

일반 `유물 공격력 증가`와 `유물 직업 피해량 증폭`은 별개의 효과다.

```text
일반 유물 공격력 증가
→ 상세창 계산 공격력에 포함

유물 직업 피해량 증폭
→ 상세창 계산 공격력에 미포함
→ 실제 타격 데미지 계산에서 적용
```

v1.376의 상세창 공격력 계산 함수는 일반 유물 공격력 필드를 읽지만 직업별 증폭 필드 다섯 개는 읽지 않는다.

## 버림 순서

직업증폭배율은 다른 데미지 계수들이 계산된 뒤 최종 데미지에 곱해진다. 그 결과를 정수로 변환하면서 소수점 이하를 0 방향으로 버린다.

```text
최종 정수 데미지
= trunc(기존 데미지 × 직업증폭배율)
```

## v1.376 내부 필드

`StatusData` 객체 기준 직업별 유물 증폭 필드는 다음과 같다.

| 효과 | 객체 오프셋 |
| --- | ---: |
| 버서커 계열 유물 증폭 | `+0x2FC` |
| 팔라딘 계열 유물 증폭 | `+0x300` |
| 레인져 계열 유물 증폭 | `+0x304` |
| 소서러 계열 유물 증폭 | `+0x308` |
| 다크나이트 계열 유물 증폭 | `+0x30C` |

대응하는 도감 직업 증폭 필드는 `+0x2A8`부터 `+0x2B8`까지 같은 직업 순서로 배치된다.

## 코드 적용 흐름

실제 데미지 계산은 다음 순서로 처리한다.

1. 공격 헌터의 기본 직업 번호를 읽는다.
2. 직업에 맞는 도감 직업 증폭 필드 하나를 고른다.
3. 직업에 맞는 유물 직업 증폭 필드 하나를 고른다.
4. 양수인 증폭값을 기본값 1에 더한다.
5. 만들어진 직업증폭배율을 실제 데미지에 곱한다.
6. 소수점 이하를 버려 정수 데미지로 저장한다.

## 검증 결과

1. 상세창 공격력 함수 전체에서 직업별 유물 증폭 필드 `+0x2FC`~`+0x30C`를 읽지 않는 것을 확인했다.
2. 별개의 전투 데미지 계산 경로 두 곳에서 공격 헌터의 기본 직업으로 해당 증폭 필드를 선택하는 것을 확인했다.
3. 두 경로 모두 도감과 유물의 같은 직업 증폭을 기본값 1에 합산한 뒤 실제 데미지에 마지막 배율로 곱한다.
4. 두 경로 모두 직업증폭 적용 후 정수 변환으로 소수점 이하를 버린다.
