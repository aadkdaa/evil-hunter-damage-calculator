# 공격력 간략공식

```text
기초공격력
= 무기공 + (2 × 고유공격력 × 무기속)
```

| 그룹 | 계산 내용 |
| --- | --- |
| A | `1 + (승전 + 지던)` |
| B | `1 + (신강 + 성격 + 연합 + 스탯 + 등급 + 비법 + 룬 + 장비 전공 + 영웅스킬)` |
| C | `건물 + 마을펫` |
| D | `1 + (코스튬 + 도감 + 인장 + 라이딩펫 + 유물)` |
| E | `1 + 요정` |
| F | `스킬·장비 공격력증폭 최종배율` |

```text
마을 공격력
= 기초공격력 × A × (B + C) × D × E × F
```

```text
콜로세움 공격력
= 기초공격력 × B × D × E × F
```

```text
초당공격력
= 최종공격력 ÷ 최종공속
```

## 연합 적용

```text
마을     → 연합 마을 공격력
콜로세움 → 연합 콜로세움 공격력
```

## 퍼센트 처리

```text
A, B, D, E = 1 + (그룹 합계 ÷ 100)
C          = 그룹 합계 ÷ 100
F          = 공격력증폭 최종배율 (증폭이 없으면 1)
```

## F 적용 원칙

```text
A~E 계산 완료 후 마지막에 F를 곱한다.

장비증폭 = 1 + (질풍·진질풍·용의 가호·강철 고삐 증폭률 합계)
스킬증폭 × 장비증폭 = 곱연산
```

현재 확인된 장비 증폭 그룹은 질풍·진질풍·용의 가호·강철 고삐가 속한 한 그룹이다.
