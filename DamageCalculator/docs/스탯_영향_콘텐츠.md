# 스탯 영향 콘텐츠

게임 내 스탯에 영향을 주는 콘텐츠별 수치를 정리한다.

## 간략 공식 이미지의 분류

| 계산 그룹 | 포함 콘텐츠 |
| --- | --- |
| A | 승전, 지던 |
| B | 신강, 성격, 연합(콜로세움 5 또는 마을 15), 스텟, 등급, 비법, 룬, 장비 |
| C | 건물, 펫 |
| D | 무기코튬, 도감, 인장 |
| E | 요정 |

## 이미지에 적힌 계산 관계

- 마을 공격력 = A × (B + C) × D × E
- 콜로세움 공격력 = B × D × E

## 추가 콘텐츠

다음 콘텐츠도 스탯에 영향을 준다.

| 콘텐츠 | 계산 그룹 |
| --- | --- |
| 펫장비 | 미정. 기존 엑셀에는 펫장비 또는 해당 옵션명이 없으며, 증폭 직접입력으로 수동 가정만 가능 |
| 유물 | 유력 가설: 사용자 공식 D 그룹(코스튬·도감·인장 계열). 힐라 검산에서 유물 공격력 12.5%를 이 그룹에 넣으면 고유공격력 약 992.2로 화면 공격력 재현 |
| 날개 | 미정 |
| 컴페 | 미정 |
| 코스튬 | 미정 |

계산 그룹이 미정인 콘텐츠는 이후 사용자가 알려 주는 내용에 따라 갱신한다.
