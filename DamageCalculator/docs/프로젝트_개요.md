# 프로젝트 개요

## 대상

- 게임명: 이블 헌터 타이쿤

## 목적

이블 헌터 타이쿤의 데미지 공식을 자료와 실험을 통해 점진적으로 복원한다.

공식을 어느 정도 복원한 뒤 APK를 분석하여 비교할 예정이다. 최종적으로는 사용자가 현재 상태를 입력하면 예상 데미지가 계산되는 Google Sheets 계산기를 만든다.

작업은 한 번에 완성하지 않고, 사용자가 결과를 직접 확인하며 조금씩 수정하는 방식으로 진행한다.

## 초기 자료

- 계산기_1.xlsx: 예전에 사용하던 데미지 계산기
- KakaoTalk_20260902_171635779.png: 사용자가 알고 있는 간략한 계산 공식
- 이후 수집할 인터넷 자료
- 이후 확보할 게임 테스트 결과와 APK 분석 결과

## Google Sheets 방향

- 처음에는 기본적인 값과 구조만 만든다.
- 사용자가 시트를 보면서 요청하는 내용에 맞춰 점진적으로 수정한다.
- 요청하지 않은 기능이나 복잡한 구성을 미리 추가하지 않는다.
