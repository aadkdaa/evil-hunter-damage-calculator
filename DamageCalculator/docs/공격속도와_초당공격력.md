# 공격속도와 초당공격력

## 확정 정보

- 공속의 최솟값은 0.25이다.
- 초당공격력 = 공격력 ÷ 공속
- 초당공격력은 주로 스킬 데미지 계산에 사용한다.
- 이 프로젝트에서는 최종공속을 항상 0.25로 고정한다.

## 무기속과 최종공속의 구분

- 무기공속 또는 무기속은 무기 자체에 붙은 기본 수치다.
- 무기속은 기존 엑셀의 기초공격력 계산에도 사용된다.
- 최종공속 0.25는 모든 공속 효과가 적용된 뒤 헌터정보에 표시되는 값이다.
- 무기속과 최종공속은 서로 다른 값으로 관리한다.

기초공격력 = 무기공 + 2 × 헌터 고유공격력 × 무기속

초당공격력 = 최종공격력 ÷ 0.25
