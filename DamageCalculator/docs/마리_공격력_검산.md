# 마리 공격력 검산

## 확인 자료

- 정보 파일: `마리정보.txt`
- 스탯 이미지: `마리스텟.png`
- 화면 공격력: 133,905,832
- 화면 초당공격력: 535,623,300
- 직업: 데드아이(레인저 계열)
- 장착 증폭: 질풍

## 적용 전제

- 최대 환생·최대 레벨이 반영된 레인저 계열 고유공격력 범위 975~1,072.5를 사용한다.
- 신강 공격력은 기존 프로젝트 기준대로 5강의 90%를 적용한다.
- 영웅심리 성격은 공격력 7%, 이동속도 7%를 적용한다.
- 공격력 화면은 마을/PvE 계산으로 본다.
- 4차 영웅스킬의 공격력 증가 50%는 B에 적용한다.
- 별도의 스킬 공격력증폭 50%와 질풍 29~30%는 F에 적용한다.
- 스킬증폭과 질풍은 서로 다른 종류의 증폭으로 보고 곱연산한다.
- 유물 공격력 12.5%는 D에 적용하고, 레인저 직업 증폭 1.75%만 제외한다.

## A~E 계산

```text
기초공격력
= 1,742,004 + (2 × 고유공격력 × 2.0)
= 1,745,904 ~ 1,746,294

A = 1 + (승전 12% + 지던 135%)
  = 2.47

B = 1 + (
    신강 90%
  + 영웅심리 7%
  + 연합 15%
  + 헌터 스탯 20%
  + 헌터 등급 6%
  + 비법 15%
  + 룬 28%
  + 장비 전공 226%
  + 영웅스킬 50%
)
  = 5.57

C = 건물 65% + 마을펫 20%
  = 0.85

D = 1 + (
    코스튬 6%
  + 도감 69.4%
  + 인장 16%
  + 라이딩펫 38.15%
  + 유물 12.5%
)
  = 2.4205

E = 1 + 요정 2%
  = 1.02
```

따라서 F 적용 전 마을 공격력은 다음 범위다.

```text
F 적용 전 공격력
= 기초공격력 × 2.47 × (5.57 + 0.85) × 2.4205 × 1.02
= 68,353,003.09 ~ 68,368,271.78
```

## 질풍 증폭률

엑셀의 질풍은 이동속도 합계의 10%를 공격력증폭으로 바꾸며, 반영 대상 이동속도는 300에서 제한된다.

```text
PvP 이속 합계
= 코스튬 60 + 인장 20 + 라이딩펫 75 + 등급 20
  + 영웅심리 7 + 비법 15 + 룬 16 + 장비 43
= 256

마을/PvE 이속 합계
= PvP 이속 256 + 건물 50
= 306

질풍 PvP 증폭 = 256 × 10% = 25.6%
질풍 PvE 증폭 = MIN(306, 300) × 10% = 30%
```

따라서 마리스텟 이미지의 마을/PvE 공격력에 적용되는 질풍은 정확히 30%로 계산된다.

## 화면 공격력 역산

화면 공격력으로 전체 F를 역산하면 다음과 같다.

```text
F = 133,905,832 ÷ F 적용 전 공격력
  = 1.958596122 ~ 1.959033633
  ≒ 1.959
```

유물 공격력 12.5%를 포함하고 직업증폭 1.75%만 제외한 상태에서 화면값이 요구하는 전체 F는 약 1.959다.

## 스킬증폭과 질풍 적용

엑셀에 없는 스킬증폭은 사용자 테스트를 기준으로 장비증폭과 곱연산한다.

```text
질풍 29%: F = 1.50 × 1.29 = 1.935
공격력 = 약 132,263,061 ~ 132,292,606

질풍 30%: F = 1.50 × 1.30 = 1.95
공격력 = 약 133,288,356 ~ 133,318,130
```

질풍 29~30%를 적용하면 화면값보다 약 58.8만~164.3만 낮다. 스킬증폭이 50%일 때 화면값을 맞추려면 질풍 증폭이 약 30.57~30.60%여야 한다.

## 초당공격력 확인

```text
133,905,832 ÷ 0.25 = 535,623,328
```

화면 초당공격력 535,623,300과 28 차이다. 기존 사례와 마찬가지로 내부 소수점 또는 중간 버림으로 설명 가능한 작은 차이다.

## 현재 결론

- 질풍 PvP 증폭은 25.6%다.
- 질풍 마을/PvE 증폭은 상한에 걸려 정확히 30%다.
- 4차 영웅스킬의 공격력 증가 50%는 이미 B에 포함되어 있다.
- 유물 공격력 12.5%는 D에 포함하고 레인저 직업증폭 1.75%만 제외했다.
- 스킬증폭 50%와 질풍 29~30%를 곱한 계산 공격력은 약 132,263,061~133,318,130이다.
- 실제 공격력 133,905,832와 정확히 맞지는 않으며, 질풍 30% 기준 약 58.8만~61.7만 부족하다.
