# 계산기 구현 범위

## 구현 예정 기능

사용자가 만드는 계산기에는 다음 기능을 구현한다.

1. 공격력 계산
2. 초당공격력 계산
3. 평타 및 종족별 데미지 계산
   - 치명타와 비치명타를 구분한다.
   - 대상 종족에 따른 피해를 함께 계산한다.
4. 증폭 버프 계산
5. 세팅 비교 기능

## 구현 보류 기능

6. 방어력 계산
7. 체력 계산

- 방어력과 체력은 헌터 생성 시 직업별 범위에서 정해지는 랜덤 원천값의 처리 방식을 결정할 때까지 구현을 보류한다.

## 범위 관리

- 위 목록은 2026-09-03 사용자가 정한 현재 구현 범위와 보류 상태이다.
- 기존 3번 `평타 데미지 계산`과 4번 `종족 피해 계산`은 하나의 기능으로 통합한다.
- 기존 `계산기_1.xlsx`에 있는 다른 기능은 사용자가 별도로 추가하기 전까지 구현 대상에 포함하지 않는다.
