# 방어력 계산공식

## 적용 범위

- 헌터 상세 정보에 저장되는 최종 방어력 계산식이다.
- 대상 APK: v1.373, v1.376
- 실행 중인 앱이나 LD플레이어는 사용하지 않고 복호화된 IL2CPP 코드와 APK 에셋만 정적 분석했다.
- 아래 식은 v1.376을 기준으로 한다. v1.373은 유물 방어력 항목만 없고 계산 구조와 버림 순서가 같다.

## 원천 방어력

헌터 생성 코드는 기본 직업 번호로 `Hunter` 데이터 행을 고른 뒤, 방어력 범위 배열의 두 번째 범위에서 정수 난수를 뽑는다. 최솟값과 최댓값을 모두 포함한다.

| 기본 직업 번호 | 직업 계열 | APK에 저장된 세 범위 | 실제 생성 범위 |
| ---: | --- | --- | ---: |
| 0 | 버서커 | 90~100 / 100~110 / 110~120 | 100~110 |
| 1 | 팔라딘 | 90~100 / 100~110 / 110~120 | 100~110 |
| 2 | 레인져 | 80~90 / 90~100 / 100~110 | 90~100 |
| 3 | 소서러 | 80~90 / 90~100 / 100~110 | 90~100 |
| 4 | 다크나이트 | 90~100 / 100~110 / 110~120 | 100~110 |

```text
원천방어력 = Random.Range(두 번째 범위 최솟값, 두 번째 범위 최댓값 + 1)
```

## 환생·레벨 계수

```text
환생계수 R = 환생 횟수가 0이면 1
             환생 횟수가 1 이상이면 환생 횟수 × 3

레벨계수 L = 1 + 레벨 × 0.003
```

예를 들어 레벨 100의 레벨계수는 `1.30`이다.

## 기본 방어력 덩어리

```text
기본방어력 = 장비 고정방어력 + 원천방어력 × R × L
```

장비 고정방어력은 현재 착용 장비에서 집계된 고정 방어력 합계다.

## 일반 방어력 합

아래 값은 `7 = 7%`와 같은 퍼센트 포인트 단위로 합산된다.

```text
일반방어력합 P
= 개인 방어력
 + 장비 옵션 방어력
 + 헌터 등급 방어력
 + 건물 방어력
 + 마을 펫 방어력 항목 1
 + 마을 펫 방어력 항목 2
 + 길드 방어력
 + 비법/GUP 방어력
```

## 직접 비율 방어력 합

아래 값은 `0.07 = 7%`와 같은 소수 비율로 저장되어 그대로 더해진다.

```text
직접방어력합 Q
= 코스튬 방어력
 + 도감 방어력
 + 라이딩펫 방어력
 + 유물 방어력
```

따라서 방어력 퍼센트 덩어리는 다음과 같다.

```text
방어력비율 = 1 + P ÷ 100 + Q
```

`P`와 `Q`는 서로 곱하지 않는다. 단위를 맞춘 뒤 하나의 덧셈 그룹이 된다.

## 스톤스킨

```text
스톤스킨배율 S = 1 + 스톤스킨 단계값 ÷ 100
```

스톤스킨이 없으면 `S = 1`이다.

## 특정 헌터 보정

내부 헌터 번호에 따라 방어력에 다음 배율이 추가된다.

| 내부 헌터 번호 | 배율 H |
| --- | ---: |
| 78, 418, 599, 600 | 1.02 |
| 360 | 1.04 |
| 748, 773 | 1.06 |
| 그 외 | 1.00 |

같은 분기에서 내부 `FairyArmorUp` 표시값도 각각 2%, 4%, 6%로 기록된다.

## 변신·마을 방어력 배율

```text
변신배율 T = PolyIndex가 48이면 1.30, 아니면 1.00

마을방어력배율 W = 1 + 내부 TownArmorUp 비율
```

`TownArmorUp`은 이미 소수 비율로 집계된 값이다. 이 단계의 코드만으로 요정·지하던전 등 세부 원천을 다시 분리할 수 없으므로 계산기에서는 집계값 하나로 다룬다.

## 최종 공식과 버림 순서

```text
1차 방어력 A0
= trunc(
    기본방어력
  × S
  × 방어력비율
  × H
  × T
  × W
)
```

`trunc`는 소수점 이하를 0 방향으로 버리는 정수 변환이다.

방어력 물약/보호막 비율이 0보다 크면 1차 방어력을 기준으로 증가량을 한 번 더 버린 뒤 더한다.

```text
물약 적용 방어력
= A0 + trunc(A0 × 보호막비율)
```

최종값은 음수가 되면 0으로 제한된다.

```text
최종방어력
= max(0, 보호막비율이 0보다 크면 물약 적용 방어력, 아니면 A0)
```

## 중요한 코드상 차이

- `GearArmorUpgrade`라는 별도 필드는 존재하지만 v1.376 최종 방어력 함수에서는 이 필드를 직접 읽지 않는다.
- 장비 강화로 생긴 방어력 증가가 있다면 앞 단계에서 `장비 옵션 방어력` 등에 합쳐져 들어와야 한다.
- 기존 엑셀의 `(1 + 요정 방어력) × (1 + 옵션 방어력) × (1 + 지던 방어력)` 구조와 APK 최종 함수는 완전히 같지 않다. APK에서는 일반 퍼센트와 코스튬·도감·라이딩·유물 비율이 덧셈 그룹이고, `TownArmorUp`만 마지막에 별도로 곱해진다.

## 검증

1. v1.376 최종 방어력 함수의 산술 명령, 필드 접근, 정수 변환 순서를 직접 복원했다.
2. v1.373의 대응 함수에서 같은 계산 구조와 버림 순서를 다시 확인했다.
3. v1.376의 헌터 생성 경로 두 곳에서 같은 원천 방어력 범위 선택과 난수 저장 방식을 확인했다.
4. v1.373과 v1.376의 `Hunter` 에셋 방어력 데이터가 동일함을 확인했다.
