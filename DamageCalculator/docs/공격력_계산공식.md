# 공격력 계산공식

## 적용 상태

이 공식을 현재 프로젝트의 **기준 공격력 공식**으로 고정한다. 이후 추가 자료나 게임 테스트에서 차이가 확인되면 다시 수정한다.

이 공식은 헌터정보 화면에 표시되는 공격력을 계산한다. 실제 평타·스킬 데미지는 별도 공식으로 계산한다.

## 계산 순서

### 1. 기초공격력

```text
기초공격력
= 무기공 + (2 × 고유공격력 × 무기속)
```

- 무기공: 현재 무기에 표시되는 공격력
- 고유공격력: 최대 환생·최대 레벨 보정을 포함한 헌터의 고유공격력
- 무기속: 무기에 붙은 공격속도 값

### 2. A: 승전·지던

```text
A = 1 + (승전 공격력 + 지던 공격력)
```

### 3. B: 헌터 공격력

```text
B = 1 + (
    신강 공격력
  + 성격 공격력
  + 연합 공격력
  + 헌터 스탯 공격력
  + 헌터 등급 공격력
  + 비법 공격력
  + 룬 공격력
  + 장비 전체공격력
  + 영웅스킬 공격력
)
```

연합 공격력은 계산 장소에 따라 다르게 넣는다.

```text
마을 계산     → 연합 마을 공격력 사용
콜로세움 계산 → 연합 콜로세움 공격력 사용
```

### 4. C: 마을 추가 공격력

```text
C = 건물 공격력 + 마을펫 공격력
```

C에는 기본값 1을 붙이지 않는다. 마을 공격력에서만 B에 더한다.

### 5. D: 독립 공격력

```text
D = 1 + (
    코스튬 공격력
  + 도감 공격력
  + 인장 공격력
  + 라이딩펫 공격력
  + 유물 공격력
)
```

유물 공격력은 APK에서 코스튬·도감·인장·라이딩펫과 같은 독립 공격력 그룹에 들어가는 것을 확인했다.

### 6. E: 요정 공격력

```text
E = 1 + 요정 공격력
```

### 7. F: 공격력증폭

```text
F = 스킬·장비 공격력증폭의 최종배율
```

- A~E까지의 공격력 계산이 끝난 뒤 마지막에 곱한다.
- 공격력증폭이 없으면 `F = 1`이다.
- 현재 확인된 같은 장비 증폭 그룹의 효과끼리는 증폭률을 합산한다.
- 스킬 공격력증폭과 장비 공격력증폭은 서로 곱한다.

```text
장비 공격력증폭 배율
= 1 + (질풍·진질풍·용의 가호·강철 고삐 중 적용되는 증폭률 합계)

F = 스킬 공격력증폭 배율
  × 장비 공격력증폭 배율
```

엑셀에서 질풍·진질풍·용의 가호·강철 고삐는 같은 개인버프 그룹이므로 서로 합연산한다. 별도의 두 번째 장비 증폭 그룹은 현재 확인되지 않았다.

## 최종 공식

### 마을 공격력

```text
마을 공격력
= 기초공격력 × A × (B + C) × D × E × F
```

### 콜로세움 공격력

```text
콜로세움 공격력
= 기초공격력 × B × D × E × F
```

콜로세움에서는 승전·지던 그룹 A와 마을 전용 그룹 C를 사용하지 않는다.

## 퍼센트 처리

각 그룹 안의 공격력 퍼센트는 먼저 합산한 뒤 소수 배율로 바꾼다.

```text
기본값이 있는 그룹
= 1 + (그룹 내 퍼센트 합계 ÷ 100)
```

```text
기본값이 없는 C 그룹
= 그룹 내 퍼센트 합계 ÷ 100
```

## F의 현재 적용 원칙

헌터정보 공격력에 실제로 반영되는 공격력증폭은 모든 일반 공격력 그룹 계산 후 F로 곱한다.

```text
F 적용 공격력
= A~E 계산 공격력 × F
```

엑셀 수식으로 같은 장비 그룹 내부의 합연산과 서로 다른 그룹 사이의 곱연산을 확인했다. 엑셀에 없는 스킬 공격력증폭은 사용자 테스트와 마리 검산을 기준으로 장비 증폭과 곱연산한다.

## 초당공격력

```text
초당공격력
= 최종공격력 ÷ 최종공속
```

이 프로젝트에서는 최종공속을 최저값으로 고정해 사용한다.

## 한 줄 요약

```text
기초공격력 = 무기공 + (2 × 고유공격력 × 무기속)

마을 공격력 = 기초공격력 × A × (B + C) × D × E × F

콜로세움 공격력 = 기초공격력 × B × D × E × F

초당공격력 = 최종공격력 ÷ 최종공속
```
