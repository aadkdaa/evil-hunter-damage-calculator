# 기존 엑셀 공식 분석

## 분석 대상

- 파일: 계산기_1.xlsx
- 계산기 버전 표기: v.1.0.4
- 핵심 시트: 계산기(복사해서쓰세요)
- 분석 기준: 사용자가 제공한 최신 정보와 맞추지 않고 기존 엑셀에 실제로 작성된 수식을 그대로 해석함

## 통합 문서 구성

통합 문서에는 총 13개 시트가 있다.

- 간단 설명서
- 계산기(복사해서쓰세요)
- 방어력계산기
- 비교계산기
- 여러 사용자별 계산기 복사본
- 측정기 원본
- 데미지검증기

비교계산기는 핵심 계산기를 좌우에 두 개 배치하여 두 설정을 비교하는 구조다. 사용자별 복사본과 측정기 원본도 같은 기본 공식을 사용한다.

## 입력 열의 의미

핵심 계산기의 D~Q열은 콘텐츠별 효과를 다음 스탯에 배분한다.

| 열 | 의미 |
| --- | --- |
| D | 이동속도 |
| E | 공격속도 |
| F | 치명확률 |
| G | 치명피해 |
| H | 공격력 |
| I | 보스 |
| J | 영장 |
| K | 악마 |
| L | 언데드 |
| M | 동물 |
| N | 모든 종족으로 보이는 공통 종족값 |
| O | 몬스터 피해 |
| P | 헌터 피해 |
| Q | 영웅 피해 |

## 콘텐츠 입력 영역

엑셀에 별도 입력 영역이 있는 콘텐츠는 다음과 같다.

- 공용: 승전, 연합버프, 지하던전, 건물, 도감, 마을 펫
- 헌터: 코스츔, 인장, 라이딩펫, 요정
- 헌터 정보: 등급, 성격, 스탯, 태생치확, 비법서, 퀴큰
- 장비 관련: 무기공, 무기속, 퓨리, 미덕, 룬, 장비, 신강
- 기타: 직업군, 영웅 4차, 증폭 효과

펫장비, 유물, 날개, 컴페는 독립 입력 항목으로 존재하지 않는다. 일부 값이 장비 또는 직접입력 항목에 합산되어 있을 가능성은 있지만 엑셀만으로는 구분할 수 없다.

## 1. 공격력 그룹

엑셀은 공격력 효과를 A, B, C, C', D라는 다섯 중간값으로 만든다. 여기의 문자 이름은 참고 이미지에 적힌 A~E 명칭과 다르므로 엑셀 내부 이름으로 이해해야 한다.

### A: 요정 공격력

A = 1 + 요정 공격력%

셀 수식:

I84 = 1 + H30%

### B: 코스츔·도감·인장·라이딩펫

B = 1 + (코스츔 공격력 + 도감 공격력 + 인장 공격력 + 라이딩펫 공격력)%

셀 수식:

J84 = 1 + (H15 + H18 + H21 + H27)%

### C: 헌터 중심 공격력 그룹

C = 1 + (연합버프 공격력 - 10 + 등급 + 성격 + 공격력 스탯 + 비법서 + 룬 + 장비 + 신강 + 영웅 4차)%

셀 수식:

K84 = 1 + ((H6 - 10) + H33 + H34 + H35 + H39 + H47 + H48 + H49 + H55)%

연합버프 공격력에서 10을 뺀 값만 이 그룹에 들어간다.

신강 입력부는 C49에 `무기:5강`이라고 표시되고 H49에 90이 직접 입력되어 있다. 강화 단계로부터 수치를 계산하는 수식이나 단계별 조회표는 없으며, 엑셀은 무기 5강을 전제로 신강 공격력 90%를 C 그룹에 더한다. 현재 무기공은 C43에 별도로 입력하므로 엑셀 구조상 무기공 입력과 신강 90%가 동시에 적용된다.

### C': 마을 중심 추가 공격력

C' = (연합버프 공격력 - 5 + 건물 공격력 + 마을 펫 공격력)%

셀 수식:

L84 = ((H6 - 5) + H12 + H24)%

이 값에는 앞의 그룹들과 달리 기본값 1이 없다. PvE에서 C에 더해지는 추가분으로 사용한다.

### D: 승전·지하던전

D = 1 + (승전 공격력 + 지하던전 공격력)%

셀 수식:

M84 = 1 + (H3 + H9)%

지하던전 공격력은 다음과 같이 계산한다.

지하던전 공격력% = (층수 - 125) × 0.5

125층보다 낮을 때 0으로 제한하는 처리는 없다.

## 2. PvP 및 PvE 공격력 배율

PvP 공격력 배율:

PvP배율 = A × B × C

셀 수식:

O84 = I84 × J84 × K84

PvE 공격력 배율:

PvE배율 = A × B × (C + C') × D

셀 수식:

P84 = I84 × J84 × (K84 + L84) × M84

수학적 구조만 보면 참고 이미지의 콜로세움 공격력과 마을 공격력 그룹 구조에 대응하지만, 엑셀에서는 그룹 문자 이름이 다른 순서로 붙어 있다.

## 3. 헌터 고유공격력과 기초 공격력

기초 공격력은 다음 식으로 만든다.

기초공격력 = 무기공 + 2 × 헌터 고유공격력 × 무기속

헌터 고유공격력은 허수아비에서 확인한 PvE 공격력을 이용해 역산한다.

고유공격력 = ((허수아비 공격력 ÷ PvE 공격력 증폭 ÷ PvE 공격력 배율) - 무기공) ÷ 무기속 ÷ 2

셀 수식:

D87 = (D85 ÷ P95 ÷ P84 - C43) ÷ C44 ÷ 2

역산 결과가 800 미만이거나 1200을 초과하면 확인필요라고 표시한다. 계산된 값을 사용자가 D89에 직접 다시 입력하는 구조다.

## 4. 최종 표시 공격력

PvE 공격력:

PvE공격력 = 기초공격력 × PvE 공격력 배율 × PvE 공격력 증폭

C92 = (C43 + 2 × D89 × C44) × P84 × P95

PvP 공격력:

PvP공격력 = 기초공격력 × PvP 공격력 배율 × PvP 공격력 증폭

D92 = (C43 + 2 × D89 × C44) × O84 × O95

## 5. 공격속도와 초당공격력

이 엑셀의 공속은 값이 작을수록 빠른 공격 간격으로 취급된다.

공속 감소 스탯:

- 퀴큰: E40
- 일반 공속: 연합버프 + 라이딩펫 + 공격속도 스탯 + 비법서
- 룬·장비 공속: 룬 + 장비

퓨리값:

퓨리 레벨이 1 이상이면 1.2 + 0.18 × 퓨리 레벨

계산 공속:

계산공속 = 무기속 × (1 - 일반공속% - 룬장비공속%) ÷ (1 + 퀴큰% + 퓨리값)

O90 = C44 × (1 - J90% - K90%) ÷ (1 + I90% + E45)

적용 공속:

적용공속 = MAX(계산공속, 0.25)

행동간격:

- 퓨리가 있으면 적용 공속을 그대로 사용한다.
- 퓨리가 없으면 최소 0.5를 적용한다.

초당공격력:

- PvE 초공 = PvE 공격력 ÷ 적용 공속
- PvP 초공 = PvP 공격력 ÷ 적용 공속

메인 초공 계산에는 행동간격 Q90이 아니라 적용 공속 P90이 사용된다.

## 6. 치명피해

기본 치명피해 배율은 1.75다.

치피 A:

A = 1.75 + (도감 + 라이딩펫 + 룬 + 장비 + 영웅 4차 치피)%

치피 A':

A' = (건물 + 마을 펫 치피)%

영웅피해:

영피 = 장비 영피%

최종 치명피해 배율:

- PvP = A + 영피
- PvE = A + A'
- Pv 영장몹 = A + A' + 영피

영피는 곱연산이 아니라 치명피해 배율에 직접 더해진다.

## 7. 치명확률

태생 치확:

태생치확 = 직업군 치확 + 태생치확 보정

직업군 보정:

- 버서커, 팔라딘, 다크나이트: 3
- 레인저, 소서러: 6

스탯 치확:

연합버프 + 도감 + 라이딩펫 + 성격 + 치확 스탯 + 비법서

장비 치확:

룬 + 장비

최종 치확:

최종치확 = MIN(100, 태생치확 + 스탯치확 + MIN(장비치확, 50))

장비에서 얻는 치확은 50으로 제한되고 전체 치확은 100으로 제한된다.

## 8. 이동속도

PvP 이속:

코스츔 + 인장 + 라이딩펫 + 등급 + 성격 + 비법서 + 룬 + 장비

PvE 이속:

PvP 이속 + 건물 이속

건물 이속은 PvE에만 추가된다.

## 9. 증폭

증폭은 공격력에 반영되는 부분과 최종 데미지에 반영되는 부분을 따로 계산한다.

각 항목에는 다음 입력이 있다.

- 증폭률
- 장착 여부
- 초공반영 여부

장착된 효과는 데미지 증폭에 포함된다. 초공반영이 체크된 효과만 공격력 증폭에도 포함된다.

### 증폭 그룹 A

개인버프 그룹으로 강철 고삐, 용의 가호, 질풍, 진질풍이 들어 있다.

- 일반 효과: 입력한 증폭률 사용
- 질풍: MIN(이속, 300) × 입력 비율
- 진질풍: MIN(이속, 400) × 입력 비율

이속이 PvP와 PvE에서 다르므로 그룹 A의 PvP·PvE 증폭값도 달라질 수 있다.

질풍의 입력 비율이 10%이고 이동속도가 300 이상이면 `MIN(이속, 300) × 10% = 30%`가 되어 증폭 배율 1.30을 만든다. 장착과 초공반영이 모두 선택된 경우 표시 공격력에도 1.30배로 반영된다.

강철 고삐 10%와 용의 가호 20%를 동시에 장착해도 그룹 합계 데미지 배율은 1.30이 된다. 다만 `신라이전용낄낄` 예시에서는 강철 고삐의 초공반영이 꺼져 있어 공격력 증폭은 용의 가호 20%만 반영된 1.20이다.

증폭 직접입력 칸에 30%를 입력하고 장착 및 초공반영을 모두 선택하는 방법으로도 표시 공격력 1.30배를 만들 수 있지만, 엑셀만으로는 그 효과의 실제 출처를 알 수 없다.

### 증폭 그룹 B

파티버프 그룹으로 신성 고삐, 배틀샤우트 등이 들어 있다.

### 증폭 그룹 C

저주의 고삐와 직접입력 항목이 들어 있다.

### 증폭 개별 그룹

대악마, 공격력 물약, 소울이터 등을 직접 입력하는 영역이다.

문서 메모에는 모두 개별 곱산이라고 적혀 있지만 실제 총합 수식은 1 + SUM(각 증폭률)이다. 따라서 같은 개별 그룹 안의 여러 효과는 서로 곱해지지 않고 합산된 뒤 다른 그룹과 곱해진다.

### 최종 증폭

각 그룹 내부:

그룹배율 = 1 + 그룹 내 활성 증폭률 합계

최종 데미지 증폭:

- PvP = 그룹A PvP 데미지 × 그룹B × 그룹C × 개별그룹
- PvE = 그룹A PvE 데미지 × 그룹B × 그룹C × 개별그룹

최종 공격력 증폭도 같은 방식으로 초공반영 열의 값만 곱한다.

따라서 엑셀에서 확인되는 장비·버프 증폭 규칙은 다음과 같다.

- 같은 그룹 안의 효과끼리는 `1 + SUM(증폭률)`로 합연산한다.
- 서로 다른 그룹 A·B·C·개별 그룹의 배율은 서로 곱한다.
- 질풍·진질풍·용의 가호·강철 고삐는 같은 개인버프 그룹 A에 속하므로 서로 합연산한다.
- 엑셀에는 별도의 스킬 공격력증폭 항목이 없어 스킬증폭과 장비증폭의 관계는 엑셀만으로 확인할 수 없다.

표시 공격력에는 공격력 증폭이 이미 포함된다. 최종 데미지 계산에서는 데미지 증폭을 곱하고 공격력 증폭을 나누어 중복 반영을 제거한다.

## 10. 종족 피해

보스 계수:

1 + (승전 보스 + 도감 보스 + 룬 보스 + 장비 보스 + 라이딩펫 공통 종족)%

영장 계수:

1 + (도감 영장 + 룬 영장 + 장비 영장 + 라이딩펫 공통 종족)%

악마·언데드·동물 계수:

각각 1 + (도감 해당 종족 + 룬 해당 종족 + 장비 해당 종족 + 라이딩펫 공통 종족)%

헌터 계수:

영장 계수와 동일한 값을 사용한다.

최종 PvE 종족 피해량 증가:

종족계수 × (1 + 미덕 몬피 + 장비 몬피)%

최종 헌터 피해량 증가:

헌터계수 × (1 + 장비 헌피)%

## 11. 최종 평타 데미지

단위 나눗수:

- B 선택: 1,000,000,000
- M 선택: 1,000,000
- K 선택: 1,000
- 미선택: 1

### 노크리

PvP 노크리:

PvP공격력 × PvP데미지증폭 ÷ PvP공격력증폭 × 헌터피해 ÷ 단위

PvE 노크리:

PvE공격력 × PvE데미지증폭 ÷ PvE공격력증폭 × 해당 종족피해 ÷ 단위

### 크리

PvP 크리:

PvP 노크리 계산식 × PvP 치명피해 배율

PvE 크리:

PvE 노크리 계산식 × 대상에 맞는 치명피해 배율

영장 대상은 Pv 영장몹 치명피해 배율을 사용하고, 나머지 PvE 종족은 PvE 치명피해 배율을 사용한다.

메인 계산기의 평타 출력에는 랜덤계수가 적용되지 않는다.

## 12. 치확 반영 초공

엑셀의 계산식:

치확반영초공 = 초공 × (1 + 치확 × 치명피해배율) × 데미지증폭 ÷ 공격력증폭 × 종족피해

일반적인 기대값 공식에서 치명피해배율이 크리 전체 배율이라면 1 + 치확 × (치명피해배율 - 1)을 사용하는 경우가 많다. 이 엑셀은 1 + 치확 × 치명피해배율을 사용하므로 일반 공격분을 한 번 더 포함하는 형태다.

동일한 치명피해배율을 크리 데미지 계산에서는 전체 곱으로 사용하고 있으므로, 이 부분은 기존 계산기의 잠재적인 과대 계산 지점이다. 다만 게임에서 치피의 의미가 추가 피해량으로 정의된다면 의도된 식일 가능성도 있어 실제 게임값과 비교가 필요하다.

## 13. 방어력계산기

방어력계산기는 메인 데미지 결과와 연결되지 않은 별도 시트다.

깡방 합계:

헌터 기본방어력 2,000 + 체크한 장비 방어력 합계

옵션 방어력%:

연합 + 스탯 + 등급 + 건물 + 도감 + 마을펫 + 라이딩 + 비법 + 룬 + 장비

지던 방어력%:

(지던 층수 - 125) × 0.5

방어력 계수:

(1 + 요정방어력%) × (1 + 옵션방어력%) × (1 + 지던방어력%)

최종 방어력:

깡방 합계 × 방어력 계수

이 시트는 적 방어력에 따른 데미지 감소 공식을 계산하지 않는다.

## 14. 데미지검증기와 랜덤계수

데미지검증기에는 다음 랜덤계수 후보가 들어 있다.

1.13, 1.10, 1.06, 1.05, 1.03, 1.00, 0.99, 0.98, 0.95, 0.92, 0.91, 0.90

실제 데미지를 각 후보 계수로 나눈 뒤 INT로 소수점 이하를 버려 기준값 후보를 만든다. 서로 다른 실제 데미지에서 같은 기준값이 두 번 이상 나오는 값을 찾아 기준 데미지를 추정하는 구조다.

이 검증기는 메인 계산기에 연결되어 있지 않다.

## 15. 발견된 문제와 주의점

### 깨진 이름 정의

통합 문서에는 제한시간, 점유시간, 틱행동, 평타, 잔여대기시간, 틱, 우선순위, 테이블, 스킬대기시간, 현재시간, 공속이라는 이름 정의가 남아 있으나 모두 REF 오류를 가리킨다.

V테이블이라는 LAMBDA 이름도 깨진 테이블 이름을 참조한다. 현재 핵심 데미지 계산식에서는 이 이름들이 직접 사용되지 않는 것으로 보인다.

### 데미지검증기의 NAME 오류

데미지검증기 C25는 QUERY와 TOCOL을 사용한다. Google Sheets에서 만든 수식이 Excel에서 호환되지 않는 형태로 저장되어 현재 NAME 오류가 발생한다.

### 반올림과 버림

- 메인 공격력·평타·초공 계산에는 명시적인 INT, FLOOR 또는 ROUND가 없다.
- 데미지검증기에서 기준값 후보를 만들 때만 INT로 소수점 이하를 버린다.
- 화면에 표시되는 자릿수와 실제 내부 계산값이 다를 수 있다.

### 증폭 개별 그룹

메모에는 개별 곱산이라고 되어 있지만 실제 수식은 그룹 안에서 합산한다. 둘 중 어느 쪽이 실제 게임 규칙인지는 별도 확인이 필요하다.

### 치확 반영 초공

치확 기대값 식이 일반적인 전체 치명배율 방식보다 크게 계산될 가능성이 있다.

### 누락된 최신 콘텐츠

펫장비, 유물, 날개, 컴페는 별도 입력 항목이 없다. 최신 계산기를 만들 때 어느 공격력·치피·치확·종족·증폭 그룹에 들어가는지 새로 분류해야 한다.
