## 화면 표시값

| 항목 | 표시값 |
| --- | ---: |
| 공격력 | 71,066,808 |
| 최종공속 | 0.25 |
| 초당공격력 | 284,267,200 |

## 입력값과 그룹

- 기초공격력 = 2,003,305 + 2 × 고유공격력 × 2.3
- A(승전·지던) = 1 + (12 + 135)% = 2.47
- B(헌터 그룹, 신강 제외) = 1 + ((15 - 10) + 스탯 20 + 등급 5 + 비법 15 + 장비 전공 196)% = 3.41
- C(마을 그룹) = ((15 - 5) + 건물 65 + 마을펫 20)% = 0.95
- D(코스튬·도감·인장·라이딩펫·유물) = 1 + (6 + 69.4 + 14 + 42 + 12.5)% = 2.439
- E(요정) = 1 + 2% = 1.02
- 행동불능이 아닐 때 공격력증폭 = 1.10

유물 공격력 12.5%는 기존 엑셀에 독립 항목이 없으므로 D 그룹에 들어간다는 가정이다.

## 신강 제외 계산

최종공격력 = (2,003,305 + 4.6 × 고유공격력) × 2.47 × (3.41 + 0.95) × 2.439 × 1.02 × 1.10

최종공격력 = (2,003,305 + 4.6 × 고유공격력) × 29.4705404136

고유공격력을 1,000으로 두면 최종공격력은 59,174,045.45다. 표시 공격력 71,066,808을 맞추려면 고유공격력이 약 88,727.71이어야 하므로 정상적인 고유공격력으로 보기 어렵다.

## 신강 배율 역산과 엑셀값 확인

신강 공격력 S를 B 그룹에 추가하면:

최종공격력 = (2,003,305 + 4.6 × 고유공격력) × 2.47 × (4.36 + S) × 2.439 × 1.02 × 1.10

고유공격력이 약 689.29이고 S가 0.88, 즉 신강 공격력 88%라면:

최종공격력 = (2,003,305 + 4.6 × 689.290044...) × 2.47 × (4.36 + 0.88) × 2.439 × 1.02 × 1.10

최종공격력 = 71,066,808

88%는 화면값을 맞추기 위해 역산한 값이며 엑셀의 실제 입력값은 아니다. 엑셀은 C49에 `무기:5강`, H49에 신강 공격력 90을 고정 입력하고 이 90%를 C 그룹에 더한다. 강화 단계에서 신강 공격력을 계산하는 수식은 없다.

엑셀의 신강 90%를 그대로 사용하고 유물 D그룹 및 조건부 공격력증폭 10% 가정을 유지하면 전체 배율은 35.5539088476이다. 이때 고유공격력이 0이어도 공격력은 약 71,225,323으로 화면 공격력 71,066,808보다 높다. 따라서 힐라의 차이는 신강값 부족이 아니라 유물 그룹 또는 조건부 증폭 반영 방식 등 다른 가정에서 찾아야 한다.

## 초당공격력

71,066,808 ÷ 0.25 = 284,267,232

화면 표시 초당공격력 284,267,200보다 32 높다. 공격력 화면 표시 전 내부 소수점 또는 중간 버림이 있다는 기존 판단과 일치한다.

## 현재 판단

- 유물 12.5%를 포함해도 신강 배율을 제외하면 공격력이 재현되지 않는다.
- 펫장비 조건부 공격력증폭 10%는 엑셀 원본의 명시 항목이 아니므로 엄격한 엑셀 기준 계산에서는 제외한다.
- 88%와 고유공격력 약 689.29의 조합은 화면값에 맞춘 역산 사례일 뿐 엑셀 기준값이 아니다.
- 엑셀 기준 신강은 무기 5강에 고정된 90%이며, 이 값을 적용하면 현재 다른 가정들과 함께 사용했을 때 공격력이 소폭 초과한다.

## 4차 스킬 확인 후 엑셀 원본 항목 재계산

- 4차 스킬 공격력 50% 증가를 확정값으로 추가한다.
- 4차 공격력 50%는 영웅스킬 공격력으로 분류하며 헌터 공격력 그룹에 합산한다.
- 기존 엑셀에 독립 항목이 없는 유물 공격력 12.5%를 제외한다.
- 펫장비의 조건부 공격력증폭 10%도 제외한다.
- 날쌘돌이 성격의 공격력 효과는 제공되지 않았으므로 0%로 둔다.

계산 그룹:

- A(요정) = 1.02
- B(코스튬·도감·인장·라이딩펫) = 1 + (6 + 69.4 + 14 + 42)% = 2.314
- C(헌터 그룹) = 1 + ((15 - 10) + 등급 5 + 스탯 20 + 비법 15 + 장비 196 + 신강 90 + 4차 50)% = 4.81
- C'(마을 그룹) = ((15 - 5) + 건물 65 + 마을펫 20)% = 0.95
- D(승전·지던) = 1 + (12 + 135)% = 2.47

PvE 공격력 배율:

1.02 × 2.314 × (4.81 + 0.95) × 2.47 = 33.580175616

최종공격력:

(2,003,305 + 4.6 × 고유공격력) × 33.580175616

고유공격력 800~1200을 사용하면 예상 공격력은 약 67,394,909~67,456,696이다. 화면 공격력 71,066,808보다 약 3,671,899~3,610,112 낮으며, 오차율은 약 -5.17%~-5.08%다. 화면값을 정확히 맞추는 역산 고유공격력은 약 24,571.14이므로 정상 범위와 맞지 않는다.

## 유물 공격력 12.5% 적용 검산

펫장비 조건부 공격력증폭은 제외하고, 유물 공격력 12.5%를 코스튬·도감·인장·라이딩펫과 같은 엑셀 B 그룹에 가산한다고 가정한다.

- B = 1 + (6 + 69.4 + 14 + 42 + 12.5)% = 2.439
- 전체 공격력 배율 = 1.02 × 2.439 × (4.81 + 0.95) × 2.47 = 35.394143616

최종공격력:

(2,003,305 + 4.6 × 고유공격력) × 35.394143616

| 고유공격력 | 계산 공격력 | 화면값과 차이 |
| ---: | ---: | ---: |
| 800 | 71,035,515.33 | -31,292.67 |
| 1,000 | 71,068,077.94 | +1,269.94 |
| 1,200 | 71,100,640.55 | +33,832.55 |

화면 공격력 71,066,808을 정확히 맞추는 고유공격력은 약 992.200028이다. 이는 엑셀이 정상 범위로 보는 800~1200 안에 있다.

따라서 힐라 표본은 유물 공격력 12.5%가 엑셀 B 그룹, 즉 사용자 간략 공식의 D 그룹에 가산될 가능성을 강하게 지지한다. 실제 고유공격력을 확인하기 전까지 그룹 배치는 유력 가설로 둔다.

## 펫장비 조건부 공격력증폭 수동입력 가정

`행동불능이 아닐 때 공격력 10% 증폭`은 라이딩펫이 아니라 펫장비 옵션이다.

엑셀에는 펫장비 및 같은 옵션명의 고정 항목이 없다. 증폭 개별 그룹의 직접입력 칸에 10을 넣고 장착과 초공반영을 체크하면 기술적으로 최종 표시 공격력에 1.10을 곱할 수 있지만, 이는 사용자가 임의로 추가하는 가정이지 엑셀 원본이 이 펫장비 옵션을 포함한다는 증거가 아니다.

참고용으로 유물은 제외하고 4차 공격력 50% 및 펫장비 공격력증폭 10%를 수동 포함하면:

최종공격력 = (2,003,305 + 4.6 × 고유공격력) × 33.580175616 × 1.10

최종공격력 = (2,003,305 + 4.6 × 고유공격력) × 36.9381931776

고유공격력 800~1200의 예상 공격력은 약 74,134,400~74,202,366이다. 화면 공격력 71,066,808보다 약 3,067,592~3,135,558 높고 오차율은 약 +4.32%~+4.41%다. 고유공격력이 0이어도 약 73,998,467로 화면값보다 높으므로, 현재 가정을 모두 동시에 적용하면 공격력이 과대 계산된다.

## 현재 부족한 정보

### 엑셀 공식에 대입할 수치가 없는 항목

- 헌터 고유공격력: 값을 직접 확인하거나 엑셀이 역산에 사용하는 허수아비 PvE 공격력이 필요하다.
- 신강 공격력%: 기존 엑셀은 무기 5강을 전제로 90%를 고정 사용한다. 다른 신강 단계 계산은 엑셀에 없다.
- 성격 공격력%: 화면에서 성격은 날쌘돌이로 확인되지만 엑셀에 넣을 공격력 수치가 제공되지 않았다. 공격력 효과가 없다면 0으로 확정하면 된다.
- 영웅 4차 공격력%: 공격력 50% 증가로 확인되어 현재는 확정값이다.

### 계산 규칙이 미확정인 항목

- 유물 공격력 12.5%가 어느 공격력 그룹에 들어가는지.
- 펫장비의 행동불능이 아닐 때 공격력 10% 증폭은 엑셀 원본에 명시된 항목이 아니다. 직접입력으로 수동 추가는 가능하지만 엄격한 엑셀 기준 계산에서는 제외한다. 실제 헌터정보 표시 공격력 반영 여부는 별도 확인이 필요하다.
- 유물의 직업 증폭 중 힐라에게 적용되는 항목과, 그것이 데미지증폭인지 공격력증폭인지.
- 장비 전공 196의 단위가 전체공격력 196%가 맞는지.
