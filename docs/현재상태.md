## 최종 목표와 화면 흐름

- 1단계 `정보 입력`: 계정 공용 정보, 헌터 기본 정보와 현재 장비 정보를 입력합니다.
- 2단계 `공격력 계산`: 입력값을 이용해 공격력과 계산 근거를 확인합니다.
- 3단계 `데미지 계산`: 대상과 전투 조건에 따른 실제 데미지를 계산합니다.
- 4단계 `장비 비교`: 현재 장비와 교체 후보의 공격력·데미지 차이를 비교합니다.
- 체력과 방어력 계산은 위 흐름이 완성된 뒤 확장합니다.
- `저장 / 로드`는 위 단계와 분리된 보조 기능으로 둡니다.

## 기준 화면

- `기본세팅`: 계정 공용 버프 입력 화면과 필드 배치 기준
- `데미지 계산 2`: 최종 계산기의 좌측 입력·우측 결과 구조와 폴딩 패턴 기준
- `기본세팅`의 전체 사용 너비는 `데미지 계산 2` 왼쪽 입력 영역과 맞춰져 있습니다.
- 폴딩 영역은 여러 개를 동시에 펼쳐둘 수 있습니다.

## 현재 기능

- `데미지 검증`은 메뉴, 화면과 관련 코드에서 삭제했습니다. 별도 요청이 없으면 다시 추가하지 않습니다.
- `방어력` 계산 화면과 코드는 정식 구현을 위해 보존하지만 현재 메뉴에서는 숨겨져 있습니다.
- 로컬 주소에서는 접속 코드 없이 바로 계산기에 들어갑니다.
- 기존 저장/로드 및 브라우저 자동 저장 기능은 유지됩니다.
- 기존 `데미지 계산`은 `계산기_1.xlsx`를 웹으로 옮긴 참고·검산용 화면입니다. 최종 UX 기준이 아니며 삭제하지 않습니다.
- `데미지 계산 2`는 사용자가 원하는 입력 방식과 디자인을 잡아둔 최종 UX의 초안입니다.

## 데미지 계산 2 구현 상태

- `헌터수치.txt`의 입력 항목을 순서대로 입력할 수 있는 폴딩 영역을 구성했습니다.
- 현재 코드에는 공격력 A~F 그룹, 마을·연합 콜로세움 공격력, 초당 공격력, 질풍 변환값과 게임 표시 공격력 오차 계산이 들어 있습니다.
- 위 계산 코드는 사용자가 요청하거나 확정한 공식이 아닙니다. 최종 공격력 공식으로 간주하지 말고 UX 정리 후 공식 문서 및 기존 엑셀과 다시 대조해야 합니다.
- `데미지 계산 2`에서는 왼쪽 폴딩 입력, 오른쪽 결과, 입력칸 크기·간격과 여러 폴딩을 동시에 펼치는 방식만 최종 화면 기준으로 사용합니다.
- 계산식 정리는 UX 구조를 확정한 뒤 진행합니다.
- 방어력과 체력의 정식 결과 계산은 원천값 처리 방식이 확정될 때까지 보류합니다.

## UX 정리 방향

- 먼저 상단 메뉴와 화면을 `정보 입력 → 공격력 계산 → 데미지 계산 → 장비 비교` 흐름에 맞춥니다.
- 입력값은 `계정 공용 정보`, `헌터 기본 정보`, `현재 장비 정보`, `전투 조건`, `자동 계산값`으로 구분합니다.
- 첫 구현 대상은 `정보 입력` 화면입니다. `기본세팅`과 `데미지 계산 2`의 입력 UI를 재사용하되 계산식은 임의로 변경하지 않습니다.
- 향후 헌터 등급, 직업, 무기 등의 기본값을 드롭다운 프리셋으로 적용하고 사용자가 개별 값을 덮어쓸 수 있게 합니다.
- 공격력 계산 화면은 결과와 계산 근거 중심으로 구성하고 정보 수정 위치로 돌아가는 동선을 제공합니다.
- 장비 비교는 A에 현재 설정을 자동 적용하고 B에서 교체할 장비 관련 값만 바꾸는 방향으로 단순화합니다.
- 구체적인 간격, 순서, 문구와 표시 항목은 사용자가 로컬 화면을 보며 주석으로 지시한 내용을 차례로 반영합니다.
