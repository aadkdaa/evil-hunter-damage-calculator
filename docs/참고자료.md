# 참고자료

## 폴더 역할

- 웹 계산기 구현: 저장소 루트
- 공식 조사와 원본 자료: `DamageCalculator`
- 계산기 코드는 저장소 루트에서 수정합니다.
- 공식의 근거와 검산 기록은 `DamageCalculator`의 분류된 Markdown 문서에서 관리합니다.

## 먼저 읽을 문서

- 조사 프로젝트 작업 원칙: `DamageCalculator/AGENTS.md`
- 프로젝트 목적과 범위: `docs\프로젝트_개요.md`
- 새 계산기 구현 범위: `docs\계산기_구현_범위.md`
- 현재 공격력 공식: `docs\공격력_계산공식.md`
- 간략 공격력 공식: `docs\공격력_간략공식.md`
- 공격속도와 초당공격력: `docs\공격속도와_초당공격력.md`
- 기존 엑셀 공식 분석: `docs\기존_엑셀_공식_분석.md`
- 조사 변경 이력: `docs\히스토리.md`

위 `docs` 경로는 모두 저장소의 `DamageCalculator` 폴더를 기준으로 합니다.

## 구현 입력 자료

- 기본세팅의 버프 항목과 순서: `버프순서.txt`
- 데미지 계산의 입력 항목과 순서: `헌터수치.txt`
- 기존 계산기와 수식: `계산기_1.xlsx`
- 헌터별 검산 자료: `마리정보.txt`, `마딜라 정보.txt`, `힐라정보.txt`와 관련 이미지
- APK 및 공격력 분석 원문: `공격력클뜯.txt`와 관련 `docs` 문서

## 자료 취급 규칙

- 엑셀, 이미지와 원본 텍스트는 덮어쓰거나 수정하지 않습니다.
- 공식이 확정되거나 판단이 바뀌면 해당 주제의 Markdown 문서를 갱신하고 `docs\히스토리.md`에 간단히 남깁니다.
- 웹 계산기의 코드 변경 내역은 별도의 히스토리 문서 대신 Git 커밋으로 관리합니다.
