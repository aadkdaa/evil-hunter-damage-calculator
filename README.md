# 이블헌터타이쿤 데미지 계산기

`계산기_1.xlsx`의 계산 항목과 수식을 웹에서 사용할 수 있도록 옮긴 정적 계산기입니다.

## 포함 기능

- PvE·PvP 공격력, 초공, 치명타·일반·기대 화력 계산
- 보스·영장·악마·언데드·동물 대상별 결과
- 두 설정 비교
- 방어력 계산기
- 실제 데미지 기반 검증기
- 브라우저에 현재 설정 저장 및 불러오기
- PC·모바일 반응형 화면

## 사용 방법

`index.html`을 브라우저로 열면 사용할 수 있습니다. 서버나 데이터베이스가 필요하지 않아 GitHub Pages에 그대로 게시할 수 있습니다.

## 기준

- 원본: `계산기_1.xlsx`
- 계산기 버전 표기: v1.0.4
- 기본 입력값을 넣었을 때 원본 엑셀의 주요 PvE·PvP 결과와 일치하도록 검증했습니다.
